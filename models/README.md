# Trained Models

This directory contains the trained PPO model used for evaluation.

## Files

- **custom_ppo_best.pt** — Best-performing trained model.
- **custom_ppo_latest.pt** *(optional)* — Latest training checkpoint.

During development, multiple reward functions, observation designs, and environment modifications were explored. Earlier experimental checkpoints are intentionally excluded from this repository to keep it lightweight and focused on the final implementation.
